# Seguridad

Trail Game es un juego estático: no tiene servidor, cuentas ni base de datos, y no envía
nada fuera del navegador. Solo guarda en él tus partidas (5 ranuras) y tus logros.

Si encuentras un problema de seguridad —por ejemplo, una partida exportada que al
importarla hace algo que no debería—, avísame en privado desde la pestaña
**Security → Report a vulnerability** de este repositorio, no en un issue público.
